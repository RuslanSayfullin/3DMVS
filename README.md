Используемые технологии: python~=3.8 

Скопируйте репозиторий с помощью команды: 
    $ git clone https://github.com/RuslanSayfullin/3DMVS.git 

Перейдите в основную директорию с помощью команды:
    $ cd 3DMVS

Создать и активировать виртуальное окружение:
    $ python3 -m venv venv
    $ source venv/bin/activate
Установить зависимости:
    $ pip install -r requirements.txt
$ Выход:
    $ deactivate

1. Правила именования и описания параметров:
MV-DP | 2 | 060 |-01 | H |
 A    | B |  C  | D  | E |

 A - Серия продуктов;
 B - Подсемейство продуктов: Число 2 означает серию DP2000 (2K), т.е. одну точку контура;
 C - Контрольное расстояние в мм;
 D - Тип лазера: 01 - длина волны лазера 405 нм;
 E - Версия продукта: H - высокопроизводительная версия;

2. Параметры работы:
Название параметра      |   Описание
частота сканирования    | Количество изображений, полученных устройством за единицу времени.

4   | Желтый        | IO_OUT1_N   | Line 1-                 | Дифференциальный выход IO 1 отрицательный
5   | Серый         | IO_IN0_N    | Line 0-                 | Дифференциальный вход IO 0 отрицательный
6   | Розовый       | IO_IN0_P    | Line 0+                 | Дифференциальный вход IO 0 положительный
7   | Синий         | IO_IN3_N    | Line 3-                 | Дифференциальный вход IO 3 отрицательный
8   | Красный       | IO_IN3_P    | Line 3+                 | Дифференциальный вход IO 3 положительный

4. Этапы процесса отладки оборудования:
Начало --> Настройка исходного оборудования --> Настройка облака точек --> Настройка карты глубины --> Конфигуряция триггера --> Калибровка системы --> Сохранение параметров --> Вывод данных --> Завершить

5. Переключение режимов изображения устройства осуществляется с помощью панели инструментов над областью предварительного просмотра изображения.
Режимы изображения:
- Оригинальный;
- Бинокулярное изображение;
- Контур фигуры;
- Изображение глубины;
- Карта яркости;
- Облако точек.

Открыть «Планировщик заданий» на Windows 10
1. Нажимаем комбинацию клавиш Win+R.
2. Прописываем команду taskschd.msc.
3. Запускаем её кнопкой OK.

Создание задачи
1. В древе директорий выбираем папку Microsoft, затем в панели действий нажимаем «Создать папку».
2. Прописываем название папки и нажимаем OK.
3. Щёлкаем по созданной папке, затем в панели действий выбираем «Создать задачу».
4. В открывшемся окне заполняем поля «Имя» обязательно и «Описание» — не обязательно. В параметрах безопасности оставляем тумблер у «Выполнять только для вошедших пользователей» и в фильтре «Настроить для:» выбираем Windows 10.
5. На вкладке «Триггеры» задать параметры для ее запуска:
begin the task: At log on
Settings: any user
6. На вкладке «Действие» определить запус программы:
Action: Start a program
Program/script: C:/Users/user/AppData/Local/Microsoft/WindowsApps/python3.12.exe
Add argument (optional): C:\Users\user\Documents\3DMVS\hello_world.py
